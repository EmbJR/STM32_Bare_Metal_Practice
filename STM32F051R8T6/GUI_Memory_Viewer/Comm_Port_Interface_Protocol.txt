
# Protocol details
## Notes
>> Synchronisation mechanisem have been applied by only move to the other command by receiving the reply from the other side.
>> If the reply failed for ~5 seconds, the last command will be retransmitted. 
>> If the subsecuence retransmittion failed after 5 tries, the application will halt the transmittion and becomes idle for waiting the user actions.
##List of Commands.
_________________________
|No		Command		Info
-------------------------
1>		0x01		Get memory continously		
2>		0x02		Get information data.
2>		0x03		Set Transfer units	// mainly used for changing the chunk sizes information in case of changing the protocol.
4>		0x04		Set Start address.
5>		0x05		Fw data
-------------------------

##List of error and status codes.
_________________________

-------------------------
1>		0x64		Successfull
2>		0x65		Error				
-------------------------

*****************************************************************************
**************************** Transmit/Reeive command *******************************
*****************************************************************************
______________________________________________________________________________
- Below is the protocol for transmitted/receive command from/to GUI and Controller.
-------------------------------------------------------------------------------------------------
Transmitt Data format:- 		   |<Header>| <CRC16> | <Length>| <Cmd>	 | <Data> |
Length:-   						   | 1 byte | 2 bytes | 2 bytes |1 bytes | n bytes|
--------------------------------------------------------------------------------------------------
>> Info about the protocol
- Header:- Fixed value 0xA5.
- CRC16:- CRC or the subsequent data without length bytes.
- Length:- length of the subsequent data.
- Cmd:- Command. The list of the commands are as follows.
	1> Read entire Memory 		(0x01)
	2> Write Memory 			(0x02)
	3> Erase Memory 			(0x03)
	4> Erase Chip   			(0x04)
	5> Reading Error   			(0x70)
	6> Chip comm error  		(0x71)
- Data:- The data can be the sub command or data related to the perticular command or any error codes.	
	
## Read entire Memory
*****************************************************************************
************************* Read entire Memory ********************************
*****************************************************************************
>> From GUI to controller
-------------------------------------------------------------------------------------------------
Transmitt Data format:- 	|0xA5  | CRC16 |0x00,0x01|  0x01  |	
							|1 byte|2 bytes| 2 bytes |1 bytes |
							
Receive from controller:- 	|  0xA5  |  CRC16 |0x01,0x0B|  0x01 |0x0,0xD0 |	Memory Data |
							|<Header>| <CRC16>| <Length>| <Cmd> |<Address>|   <Data>    |
							| 1 byte | 2 bytes| 2 bytes |1 bytes| 2 bytes | 264 bytes   |
	
Receive from controller in ncase of CRC checksom error:- 	
							|  0xA5  |  CRC16 |0x00,0x01|  0x70 |
							|<Header>| <CRC16>| <Length>| <Cmd> |
							| 1 byte | 2 bytes| 2 bytes |1 bytes|
--------------------------------------------------------------------------------------------------

	
## Sample Commands
*****************************************************************************
********************* Sample Read entire Memory ****************************
*****************************************************************************
- The below example shows the command fired by GUI to microcontroler at once and the microcontroller will revert the entire memory of 2048 pages buffer with chunks of 264 bytes values repeating about 2048 times.
-------------------------------------------------------------------------------------------------
>> From GUI to controller for requesting memory:- 	|0xA5|CRC16|0x00,0x01|0x01|
>> From controller to GUI for memory data:- 		|0xA5|CRC16|0x01,0x0B|0x01|0x00,0x01|264 bytes of data|
>> From GUI to controller for synchronization:- 	|0x01|CRC16|
>> From controller to GUI for memory data:- 		|0xA5|CRC16|0x01,0x0B|0x01|0x00,0x02|264 bytes of data|
>> From GUI to controller for synchronization:- 	|0x01|CRC16|
>> From controller to GUI for memory data:- 		|0xA5|CRC16|0x01,0x0B|0x01|0x00,0x03|264 bytes of data|
>> From GUI to controller for synchronization:- 	|0x01|CRC16|
													  :	:	:	:	:	:	:	:	:	:	:	:	:
													  :	:	:	:	:	:	:	:	:	:	:	:	:
													  :	:	:	:	:	:	:	:	:	:	:	:	:
>> From controller to GUI for memory data:- 		|0xA5|CRC16|0x01,0x0B|0x01|0x08,0x00|264 bytes of data|
>> From GUI to controller for synchronization:- 	|0x01|CRC16|

>> From controller to GUI for Reading error:- 		|0xA5|CRC16|0x00,0x01|0xXX|Status Code|
--------------------------------------------------------------------------------------------------
